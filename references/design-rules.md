# Design Rules

## 視覚的階層（60-30-10ルール）

- **60%**: 背景（`#232F3E`）
- **30%**: セカンダリ要素（枠線、薄いグレー）
- **10%**: アクセント（`#FF9900`で強調）

## フォントサイズ

**原則: 会場の後方席からでも読めるサイズにする。迷ったら大きい方を選ぶ。**

| 用途 | サイズ | 最小 |
|------|--------|------|
| 見出し・強調 | 28-32pt | 24pt |
| 本文（メイン） | 24pt | 20pt |
| 本文（サブ） | 20pt | 18pt |
| 補足説明 | 16-18pt | 14pt |
| 注釈・キャプション | 14pt | 12pt |
| コードブロック | 12pt | 10pt |

- 本文は最低20pt以上。18pt未満の本文は使わない
- テーブル内テキストは最低13pt、推奨14pt以上
- 矢印ラベル・アイコンラベルは最低11pt、推奨12pt以上
- 情報量が多くてサイズを下げたくなったら、スライドを分割する方が良い

## テキストのコントラスト

- 暗い背景 → 白テキスト（`#FFFFFF`）
- 明るい背景 → 黒テキスト（`#000000`）
- 図形内テキスト: `"text": "{{#FFFFFF:白テキスト}}"`

## 絵文字の使用禁止

スライドに絵文字を使用しない。`icon-search --type general`でアイコンを使用する。

## アイコン選択

- 一般的な概念 → `--type general`
- 実際のAWSサービス → 対応するAWSアイコン

## グラデーション

目立たせたり、変化を表すときに使用する。
使いすぎるとチープになるので注意する。

### 色の選択
２色のグラデーションでは同系色・隣接色相を使うと自然なグラデーションになる。
異なる概念をつなげるときに異なる系色のグラデーションも効果的。
stopsを複数指定し、カラフルなグラデーションも可能。

### opacity
stopsのパラメータとしてopacityも指定可能

```json
  {"position": 0.3, "color": "#FFFFFF", "opacity": 1},
```
